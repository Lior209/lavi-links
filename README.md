# פורטל קישורים למורי תיכון דעת לביא 🏫

פורטל אינטרנטי מהיר, מודרני ועצמאי המרכז את כל הקישורים, המערכות הפדגוגיות והטפסים השימושיים לסגל ההוראה בתיכון דעת לביא.

## 🚀 מאפייני האתר
- **עיצוב מודרני מותאם מותג:** מבוסס על צבעי הלוגו הרשמי של התיכון (כחול עמוק, כחול רויאל, כתום וירוק).
- **התאמה מלאה למובייל:** עיצוב רספונסיבי מהיר ונוח לשימוש בסמארטפון, טאבלט ומחשב.
- **חיפוש חי מהיר:** סינון מיידי של קישורים ומערכות לפי כותרת או תיאור.
- **סינון לפי קטגוריות:** מעבר מהיר בין נושאים (הכל, מערכות מרכזיות, כלים יומיומיים, חינוך ותלמידים, ניהול ומשאבים, דיווחים וטפסים).
- **הנחיות כניסה למלם שכר:** חלונית הדרכה על בחירה ב-SMS עם כפתור העתקה בלחיצה אחת לקוד חברה `1945`.
- **העתקת קישורים מהירה:** כפתור העתקת קישור עם הודעת חיווי צפה לשיתוף קל בווטסאפ.
- **עצמאי וללא תלויות כבדות:** קובץ HTML יחיד ומהיר יחד עם לוגו וקטורי `logo.svg`.

## 🌐 פריסה ל-GitHub Pages לקבלת קישור קבוע וחינמי

כדי שהאתר יהיה זמין לכל המורים ברשת תחת כתובת קבועה בחינם (למשל: `https://<username>.github.io/lavi-links/`):

### אפשרות 1: העלאה ישירה דרך אתר GitHub (פשוט ומהיר - 2 דקות)
1. היכנסו לחשבון שלכם ב-[GitHub.com](https://github.com).
2. לחצו על **New Repository** (מאגר חדש).
3. תנו שם למאגר, למשל: `lavi-links` (או `lavi`). ודאו שהמאגר מוגדר כ-**Public** ולחצו **Create repository**.
4. בעמוד שייפתח לחצו על הקישור **uploading an existing file**.
5. גררו את הקבצים:
   - `index.html`
   - `logo.svg`
   - `README.md`
   ולחצו **Commit changes**.
6. עברו ללשונית **Settings** (הגדרות המאגר) -> בעמודה הימנית/שמאלית בחרו **Pages**.
7. תחת **Branch**, בחרו ב-`main` (ובתיקייה `/root`) ולחצו **Save**.
8. תוך כדקה האתר שלכם יהיה באוויר בכתובת שתופיע בראש עמוד ה-Pages!

## 📁 מבנה הקבצים
- `index.html` - קוד האתר המלא (כולל סגנונות עיצוב ופונקציונליות JavaScript).
- `logo.svg` - לוגו וקטורי רשמי של תיכון דעת לביא.
- `README.md` - מדריך זה.
